# Build Vitals by DK — step by step

This is one web page (`index.html`). You do NOT need to install anything to use it on Vercel.
To try it on your own computer, you only need a web browser.

---

## PART A — Try it on your computer (2 minutes)

1. Find the folder `build-vitals-v2` you downloaded.
2. Double-click `index.html`.
3. It opens in your web browser. That's it. You are running the app.
4. Type a project name at the top. Your work saves on its own.

Tip: use Chrome, Edge or Firefox.

---

## PART B — Put it on GitHub (where your code is kept)

1. Go to **github.com** and log in.
2. Click the **+** at the top right, then click **New repository**.
3. In "Repository name", type: `build-vitals-by-dk`
4. Pick **Private** (only you can see it) or **Public**.
5. Do NOT tick any boxes like "Add a README". Click **Create repository**.
6. On the next page, click the link that says **uploading an existing file**.
7. Drag `index.html` and `README.md` from the `build-vitals-v2` folder into the box.
8. Scroll down and click **Commit changes**.

Your code is now on GitHub.

---

## PART C — Put it on the internet with Vercel (so anyone can open it)

1. Go to **vercel.com**. Click **Sign Up** and choose **Continue with GitHub**.
2. Click **Add New…**, then **Project**.
3. You will see your GitHub repositories. Find `build-vitals-by-dk` and click **Import**.
4. Leave every setting as it is. Do not change anything.
5. Click **Deploy**. Wait about one minute. You will see confetti.
6. Click the picture or the link Vercel shows (it looks like `build-vitals-by-dk.vercel.app`).
7. That link is your app. Send this link to testers.

To update the app later: on GitHub, open `index.html`, click the pencil icon, make your change, click **Commit changes**. Vercel updates the link by itself.

---

## Create an account and sign in (for testers)

1. Open your app link (or double-click `index.html`).
2. Click **Create account**.
3. Type a username (3 to 20 letters, numbers, dot, dash or underscore).
4. Type a password (at least 6 characters) and type it again to confirm.
5. Click **Create account**. The app opens and your work is kept under your name.
6. To leave, click **Log out** at the top right. To come back, click **Sign in**.

Important:
- Accounts are saved in the browser you used to create them. Sign in from that same browser.
- There is no "forgot password" button yet. If you forget a password, the app owner can help you start a new account.

---

## What works and what does not (for now)

Works on Vercel and on your computer:
- Projects, calendar, daily work log, workers on site, materials, BOQ typing, stages, Pay tab, Summary, and PDF downloads.

Not working yet in this version:
- **Reading a BOQ from a photo or PDF automatically.** This needs a private key that must be kept on a server. We can set that up in the next stage.
- **Seeing the same data on another phone or computer.** Data is saved in the browser you use. Use the same browser and the same device for your records.

Important: testers' data stays in their own browser. Ask testers to keep using the same browser so they don't lose their entries.
